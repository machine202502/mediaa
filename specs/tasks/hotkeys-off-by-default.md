# Глобальные хоткеи выключены по умолчанию

## Решение

`HotkeySettings::default()` даёт `enabled = false`. Пользователь включает глобальные клавиши
явно галочкой в настройках; без этого приложение не регистрирует их.

Сохранённое значение не мигрируется: если в `settings.toml` уже записано `enabled = true`,
оно остаётся в силе, пока пользователь не снимет галочку. Это соответствует правилу «нет
миграций и обратной совместимости для старых настроек».

## Файлы

- `crates/core/src/settings.rs` — `#[derive(Default)]` для `HotkeySettings`, тест на дефолт.
- `crates/app/src/app/tests.rs` — notice-тесты сериализованы общим UI-мьютексом, чтобы смена
  локали не влияла на снапшоты и тексты при параллельном прогоне.
- `specs/constraints.md` — правило про выключенные по умолчанию хоткеи.
- Снапшоты `settings-wide`, `settings-russian-light` обновлены после просмотра diff (галочка
  снята, поля хоткеев неактивны).
