# Уведомления включены по умолчанию и уведомление об очереди конвертации

## Цель

1. Настройка «Уведомления в приложении» включена по умолчанию, в том числе после сброса настроек.
2. Отправка файлов на конвертацию из библиотеки показывает уведомление: в свёрнутой карточке —
   что файлы добавлены в очередь, при развороте — имена этих файлов.

## Решение

- `Settings::default().notifications_enabled = true`. `reset_settings_values` собирает настройки из
  `Settings::default()`, поэтому сброс снова включает уведомления.
- `App::open_in_convert_many` после `conversion.add_inputs` добавляет уведомление уровня `Info`:
  `summary` — `convert.queued` с количеством файлов, `detail` — по одному имени файла на строку
  (полный путь только если у пути нет имени).
- Переход на вкладку «Конвертировать» по-прежнему не выполняется (см.
  [library-convert-no-navigation.md](library-convert-no-navigation.md)); уведомление заменяет
  прежнее «молчаливое» добавление.

## Затронутые файлы

- `crates/core/src/settings.rs` — значение по умолчанию и тест;
- `crates/app/src/shell/actions.rs` — уведомление очереди;
- `crates/app/locales/en.toml`, `crates/app/locales/ru.toml` — `convert.queued`;
- `crates/app/src/shell/ui_tests.rs` — уведомление из карточки и из выделения, переключатель;
- `crates/app/src/ui/pages/settings.rs` — тест сброса настроек;
- `crates/app/tests/snapshots/settings-*.png` — галочка «Уведомления в приложении» в расширенных
  настройках (обновлены после просмотра diff).

## Проверка

- `cargo test -p mediaa-core --lib` — 155 passed (уведомления включены по умолчанию, явное
  `notifications_enabled = false` выключает);
- `cargo test -p mediaa --lib` — 389 passed: карточка и выделение дают уведомление с именами в
  деталях, сброс включает уведомления, переключатель в расширенных настройках выключает их;
- `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets`.

## Материальные риски

- Уведомления теперь показываются у всех, кто их не выключал; сброс настроек включает их снова.
- Уведомление о очереди — `Info` с обычным сроком жизни (5 с); разворот карточки продлевает его
  до 8 с.
