# Одинаковая длительность многоканальной записи

## Причина рассинхрона

Источники стартовали не одновременно:

1. `RecordingSession` создавал и запускал каждый capture-поток по очереди;
2. поток ждал готовности своего источника (WGC/окно/монитор) и сразу начинал захват;
3. первый источник успевал записать несколько кадров, пока второй ещё инициализировался;
4. `SlotTracker` привязывал кадры к общему времени сессии, поэтому у второго источника
   первые слоты оказывались пропущены — ролик получался короче.

Дополнительно на остановке потоки замечали `stop` в разное время: один успевал записать
последний слот, другой нет. Это давало расхождение ещё в один кадр.

## Исправление

- Добавлен общий `StartGate`: все capture-потоки проходят инициализацию и ждут, пока
  поднимутся **все** источники.
- После этого `Control::begin()` фиксирует общий origin захвата **отдельно** от аудио-часов:
  аудио продолжает идти от старта сессии, а слоты видео начинают отсчёт с 0 одновременно.
  Затем gate открывается — все источники начинают с одного слота 0.
- `Control::stop()` останавливает все источники сразу, без ожидания самого длинного.
- После сборки все выходы подрезаются под **минимальную** фактическую длительность:
  WebP — нативно по ANMF-кадрам, видео — потоковым trim, GIF — перекодированием.
  Более длинные дорожки теряют хвост; кадров после нажатия «стоп» не появляется.

Итог: набор записей имеет одинаковую длительность; медленный источник определяет общую
границу, а не наоборот.

## Тесты

- `sources_starting_at_different_times_have_equal_duration` — второй источник стартует на
  250 мс позже; длительности равны в пределах одного кадра.
- `a_slow_source_is_trimmed_to_the_shared_duration` — один источник отдаёт кадры на 90 мс
  медленнее; более длинный выход подрезается под короткий.
- `a_slow_animated_source_keeps_the_shared_duration` — то же для WebP.
- `a_slow_gif_source_keeps_the_shared_duration` — то же для GIF.
- `trimming_animation_keeps_only_the_common_duration` — точная обрезка последнего кадра WebP.

Полный прогон: media pipeline **35**, media lib **46**, webp-pipeline **18**, core **138**,
app **264**, storage **16**; `clippy` чистый.
