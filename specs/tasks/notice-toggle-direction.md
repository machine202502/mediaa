# Направление стрелки в уведомлениях

## Цель

Стрелка разворота сообщения в уведомлении должна показывать, куда раскрывается карточка.

## Причина

Список уведомлений прижат к правому нижнему углу окна
(`ui/notices.rs`: `egui::Area::anchor(Align2::RIGHT_BOTTOM, …)`). Нижняя граница карточки
закреплена, поэтому при раскрытии карточка растёт вверх: строка заголовка поднимается, а
подробности появляются ниже неё. Свёрнутая карточка показывала `CARET_DOWN`, то есть стрелку в
сторону, противоположную фактическому раскрытию.

## Решение

- свёрнутое уведомление показывает `CARET_UP` — раскрытие идёт вверх;
- раскрытое показывает `CARET_DOWN` — нажатие сворачивает;
- клик по тексту уведомления по-прежнему переключает то же состояние.

## Затронутые файлы

- `crates/app/src/ui/notices.rs` — выбор иконки и тест взаимодействия;
- `crates/app/tests/snapshots/notices.png`, `notices-layers.png` — обновлены после просмотра diff.

## Проверка

- `cargo test -p mediaa --lib notice` — свёрнутое состояние показывает `CARET_UP`, раскрытое —
  `CARET_DOWN`; раскрытие/сворачивание работают;
- UI-снапшоты уведомлений;
- `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets`.
