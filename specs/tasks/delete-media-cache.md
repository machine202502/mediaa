# Удаление кэша при удалении медиа

При удалении файла из библиотеки (обычное удаление и массовая очистка) теперь удаляются оба
вида preview-кэша:

- обычный proxy (`<hash>.mp4`);
- hover-прокси (`hover-<hash>.mp4`).

Запись миниатюры из atlas-кэша удаляется существующим `Thumbnails::forget` → `Msg::Forget`:
поток миниатюр убирает слот из БД и освобождает/удаляет страницу атласа.

Удаление выполняется сразу после успешного move-to-trash; если файл не удалось удалить,
его кэш остаётся нетронутым. Ошибка удаления кэша не мешает удалению остальных файлов и
попадает в отчёт очистки.

## Тест

`app::features::library::tests::cleanup_continues_after_a_failed_move_and_removes_ready_proxies`
создаёт для каждого файла обычный и hover-прокси, затем проверяет:

- у удалённых файлов исчезли оба прокси;
- у файла, который не удалось переместить, оба прокси остались;
- очистка продолжается после ошибки.
