# Полные hover-превью через лёгкий прокси

## Решение

- Hover-превью снова покрывает **всю длительность** ролика, без обрезки до 3 секунд.
- Для наведения используется отдельный лёгкий прокси: **360p, 15 fps**, полная длительность.
- Прокси строится лениво: при первом наведении, если его нет, карточка показывает обычную
  миниатюру, а генерация идёт в фоновом потоке `hover-proxy`.
- Когда прокси готов, следующее наведение проигрывает полный ролик из маленького MP4 быстро.
- Тяжёлый исходный файл для hover больше не декодируется.

## Файлы

- `crates/media/src/preview_cache.rs` — `hover_proxy_path`, `ready_hover_proxy`,
  `ensure_hover_proxy`; общий `ensure_at` с параметрами высоты/FPS; отдельный hash и версия.
- `crates/app/src/features/library/hover_preview.rs` — полная длительность, выбор hover-прокси,
  фоновый `ensure_hover_proxy`, отсутствие крутилки до готовности.
