# Настройки превью

## Опции

Обе включены по умолчанию:

- **Анимированные превью** (`animated_previews`) — hover-анимация карточек и её лёгкий
  hover-прокси.
- **Видео-превью для полного просмотра** (`full_preview_videos`) — обычные preview-прокси,
  которые просмотрщик использует для быстрого открытия роликов.

## Выключение

При выключении опции:

- соответствующая генерация прекращается: новые `ensure_*` не стартуют, текущая WebP-генерация
  проверяет флаг на каждом кадре, готовая работа с выключенным флагом не коммитится;
- удаляются файлы только этой категории из `<медиа>/.cache/previews`:
  - анимированные — `hover-*.mp4`;
  - полные — остальные `*.mp4`;
- hover-превью останавливаются, библиотека перестаёт запускать анимацию.

Включение обратно не удаляет ничего; кэш просто начнёт заполняться заново.

## Файлы

- `crates/core/src/settings.rs` — поля и тест значений по умолчанию.
- `crates/app/src/pages/settings.rs` — секция «Превью» и вызов `preview_options_changed`.
- `crates/app/src/app.rs` — установка флагов при старте, остановка hover и очистка кэша.
- `crates/media/src/preview_cache.rs` — флаги категорий, `clear_previews`, отдельное имя
  `hover-*.mp4`.
- `crates/app/src/features/library/{mod.rs,grid.rs}` — отключение hover-превью.
