# Пакетная конвертация

## Цель

Позволить выбрать несколько файлов и последовательно конвертировать их в один
общий формат. Выбор формата ограничен матрицей совместимости всех выбранных
файлов.

## Решения

- Один целевой формат на всю пачку.
- Файлы конвертируются по одному, в порядке списка.
- Если общего формата нет, целевые кнопки неактивны, Convert неактивен.
- Во время конвертации список файлов и целевой формат заблокированы.
- Выбор файлов: многозначный file dialog и drag&drop нескольких файлов.
- Дубликаты путей схлопываются.
- Оценки размера и времени убираются полностью: `Estimate`, `estimate_size`,
  строка оценки и связанные locale-ключи удаляются.
- Ошибочный файл не останавливает пачку.
- Упавший файл подсвечивается; в Convert это строка списка, поэтому «Повторить» —
  кнопка в этой строке, а не на карточке библиотеки.
- Retry запускает только этот файл; успешные не трогаются.
- При повторе используется то же финальное имя, если оно свободно, иначе суффикс.
- Каждый файл пишется во временный output; финальный файл публикуется только после
  успеха.
- При отмене завершённые файлы остаются; temp текущего удаляется; файлы, до которых
  очередь не дошла, не конвертируются.
- Имя по умолчанию: `<stem>.<ext>`; при коллизии `-2`, `-3`; исходный файл не
  перезаписывается.
- Папка назначения — текущая output-папка конвертации.

## Матрица

| Источник | Video | Anim | Still | Audio |
|---|---|---|---|---|
| Video со звуком | да | да | да | да |
| Video без звука | да | да | да | нет |
| GIF/WebP animation | да | да | да | нет |
| Image | нет | нет | да | нет |
| Audio | нет | нет | нет | да |

- Image → Anim запрещён и для одного файла, и в пачке.
- Image → Video запрещён и для одного файла, и в пачке.
- Извлечение кадра из видео/анимации в Still разрешено везде.
- MP4 без аудио несовместим с аудио-форматами.
- Для пачки цели — пересечение возможностей всех успешно прочитанных файлов.

Примеры:

- MP4 + MP3 → только Audio;
- MP4 + PNG → только Still;
- MP4 + GIF → Video/Anim/Still;
- MP4 без звука + MP3 → общего формата нет;
- Image + Image → только Still;
- Audio + Audio → только Audio;
- Audio + Image → общего формата нет.

## Ошибки и отмена

- Probe-ошибка не блокирует остальные файлы: битый файл помечается failed и имеет
  retry; матрица считается по успешно прочитанным.
- Если все файлы не прочитались, Convert неактивен.
- Ошибка конвертации удаляет temp, строка остаётся красной с retry.
- Отмена останавливает очередь; частичный output текущего файла удаляется.
- Уже завершённые файлы остаются в папке и в списке со статусом «готово».

## UI

- Список выбранных файлов: имя, тип, размер, статус (ожидает/probe/конвертация/
  готово/ошибка/отменено).
- Прогресс: «Файл 2 из 5» и прогресс текущего файла.
- Упавшая строка красная, с кнопкой «Повторить».
- Нет строки оценки размера и времени.
- Если после добавления файла текущий target стал несовместим, target сбрасывается
  и показывается «выберите общий формат».

## Тесты

Тесты — обязательная часть задачи. UI-снимки и интерактивные тесты пишутся вместе с
реализацией, а не после.

- Матрица: все пары source/target, включая silent video, image и animation.
- Пачка: MP4+MP3 → audio only; MP4+PNG → still only; MP4+PNG+MP3 → нет цели;
  MP4 silent + MP3 → нет цели.
- Очередь: порядок, имена, коллизии, запрет перезаписи исходника.
- Отмена: завершённые остаются, текущий temp удалён, pending не созданы.
- Ошибка: пачка продолжается, failed-строка и retry.
- Drag&drop нескольких файлов.

## UI-тесты и snapshots

Всё проверяется через `egui_kittest` + PNG-snapshots.

Обязательные снимки:

- `convert-batch-list` — 3–5 файлов, статусы, выбранный общий формат;
- `convert-batch-no-target` — матрица не даёт общего формата: целевые кнопки
  неактивны, Convert неактивен;
- `convert-batch-progress` — «Файл 2 из 5» и прогресс текущего;
- `convert-batch-failed` — упавшая строка списка с кнопкой «Повторить»;
- `convert-batch-cancel` — завершённые готовы, текущий отменён, остальные не начаты;
- `convert-batch-narrow` — список и настройки на минимальной ширине;
- `convert-batch-russian-light` — русская светлая тема.

Интерактивные тесты:

- добавить/убрать файл из списка, дубликаты не появляются;
- при несовместимости target сбрасывается;
- старт конвертирует строго по порядку;
- отмена оставляет завершённые и удаляет temp текущего;
- retry перезапускает только упавшую строку;
- имена и коллизии не перезаписывают исходники;
- drag&drop добавляет файлы;
- строки оценки нет ни в одном состоянии.

## Как это выглядит

```text
Convert
Входные файлы (3)
[clip-1.mp4   видео   готово]
[clip-2.mkv   видео   конвертация 42%]
[clip-3.mp3   аудио   ошибка   [Повторить]]

Формат: MP3
[Convert]
```
