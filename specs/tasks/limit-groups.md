# Группы лимитов и вкладка «Параметры»

План реализован по LIMIT-1. Другая модель может делать по этому файлу, не по переписке.

Решения пользователя, 28.10.26. Поздняя фраза отменяет раннюю: сначала прозвучало «группа Single для всех», затем «по умолчанию лимита нет, группу к провайдеру привязывают по желанию». В плане действует вторая фраза.

Решения пользователя, 29.10.26: по умолчанию пулов нет, список пуст; в интерфейсе сущность называется «пул» (в коде остаётся тип `Group`).

## Зачем

Пользователь ограничивает, сколько запросов одновременно уходит на локальные модели и в сеть. Одна цифра на группу. Несколько провайдеров могут стоять в одной группе и делить её слоты. Инструменты лимитируются отдельно. Сейчас единственный такой инструмент — поиск в интернете, вместе с чтением страницы.

## Что есть сейчас

Слоты считает `crates/agent/src/slots.rs`. Ключ слота — `WorkKind`: агент, расшифровка, индексация, поиск, провайдеры. Лимиты лежат в `Budget` (`crates/core/src/agent.rs`). Вкладка `crates/app/src/pages/agent/budget.rs` показывает пять чисел. Очередь в `queue.rs`, карточка «Загрузка», рисует те же пять видов.

Интерактивный запрос в `Slots::request` вставляется перед фоновыми того же вида. Из-за этого фоновый запрос может ждать бесконечно, пока приходят новые интерактивные.

Отдельные пулы очереди в `crates/agent/src/run.rs`, функция `pools`, ещё раз режут расшифровку, индекс, агента и провайдеров по тем же числам. Это второй лимит поверх слотов.

Поиск в интернете нарисован в `crates/app/src/pages/agent/providers.rs`, функция `web`.

Вызовы:

- чат агента берёт `WorkKind::ProviderCalls` в `crates/agent/src/assistant/brain.rs`;
- поиск по записям берёт `WorkKind::Agent` или `WorkKind::Indexing` в `crates/agent/src/search.rs`;
- веб берёт `WorkKind::WebSearch` в `crates/agent/src/assistant/mod.rs`, функция `web_calls`.

## Данные

`Budget` и пять полей удалить. `WorkKind` удалить, когда на него больше никто не ссылается.

Группа:

- `name`: короткая латиница. Первый символ `A–Z` или `a–z`, дальше буквы и цифры. Длина от 1 до 16. Пробелы запрещены. Сравнение имён чувствительно к регистру. `Single` и `single` — разные имена.
- `limit`: целое от 1 до 16. Ноль не допускается.

В `AgentSettings` список групп; по умолчанию он пуст.

У `Connection` новое поле `group: String`. Пустая строка значит «группа не выбрана». В сериализации пустая строка — значение по умолчанию. Старый файл без поля читается как пустая строка.

Провайдер без группы не занимает слот. Его запросы не ждут.

Провайдер с группой занимает один слот этой группы на время одного запроса к модели: чат, эмбеддинг, реранк, расшифровка, список моделей, проверка имени, pull Ollama. Слот отпускается, когда запрос закончился, в том числе ошибкой или отменой.

Один и тот же слот не вложенный. Пока запрос держит слот, повторный захват той же группы в том же вызове не делается.

Инструмент «Поиск в интернете» имеет свой лимит, тоже от 1 до 16, по умолчанию 2. Это число лежит в настройках рядом с группами, не внутри группы. И `web_search`, и `web_read` берут слот этого лимита. Других инструментов в этот лимит не добавлять.

Миграцию старых чисел бюджета не писать. Лишние поля старого `Budget` в toml игнорируются. Если файл настроек не разбирается целиком, поведение `Settings::load_from` не менять.

## Слоты

`Slots` больше не знает `WorkKind` и `Budget`.

Два независимых пула:

- группы, ключ — имя группы;
- инструмент, один ключ поиска в интернете.

У каждого ключа своя очередь ждущих и свой счётчик занятых. Лимит группы берётся из настроек в момент решения, не замораживается навечно в старом `Budget`. `set_budget` заменить на обновление списка групп и лимита инструмента. Уменьшение лимита не срывает уже выданный слот. Новые ждут, пока занятых не станет меньше нового лимита. Удаление группы, пока в ней есть занятые или ждущие: ждущие этой группы больше не ждут и идут без слота; занятые дорабатывают и слот не выдают следующему.

Честность, внутри одного ключа:

- очередь строго FIFO;
- новый запрос встаёт в хвост;
- интерактивный не обгоняет того, кто уже ждёт;
- слот получает самый старый ждущий этого ключа, если занятых меньше лимита.

Чужие ключи друг друга не блокируют. Заполненная группа `A` не мешает группе `B` и не мешает провайдеру без группы. Заполненный поиск не мешает группам.

Голодание закрыто FIFO: у ждущего конечное число запросов впереди, и это число не растёт от новых обгонов. Отдельный приоритет, старение и «по кругу между задачами» не добавлять. Круг уже есть, потому что каждый ключ обслуживается независимо, а внутри ключа порядок один.

`Status` для интерфейса очереди: по каждой группе имя, занято, лимит, сколько ждёт; отдельно то же для поиска. В статус попадают все группы из настроек, даже с нулём занятых. Поиск попадает всегда.

## Где брать слот

Перед вызовом модели узнать подключение запроса. Если у него пустая группа, слот не брать. Если группа есть, взять слот этой группы и держать его до конца вызова.

Это касается чата, эмбеддингов, реранка, расшифровки, списка моделей, проверки модели и pull. Не оставлять старый `WorkKind::ProviderCalls` на все чаты сразу: два провайдера в разных группах не должны делить один общий потолок «провайдеры».

Поиск по записям больше не берёт слот вида «агент» или «индексация». Его слот — группа провайдера эмбеддингов, и только если она задана. Реранк берёт группу своего провайдера, если задана.

`pools` в `run.rs` не должен второй раз резать те же запросы. Ёмкости `Speech`, `Embed`, `Llm`, `Provider` поставить большими и постоянными, чтобы очередь задач пускала работу к слотам, а не держала её своим потолком. Числа бюджета туда больше не передавать.

## Интерфейс

Вкладка, которая сейчас называется «Бюджет», называется «Параметры». Идентификатор страницы `--page=budget` не менять, чтобы старые вызовы страницы открывали её. Меняется видимое имя в `en.toml` и `ru.toml`.

На вкладке два блока.

Группы (в интерфейсе — «Пулы»):

- список: имя и лимит;
- лимит меняется на месте;
- кнопка добавления: поле имени и лимит, по умолчанию лимит 1;
- недопустимое имя или повтор не добавляются, показывается текст ошибки;
- удаление группы. Провайдеры, у которых было это имя, становятся без группы.

Поиск в интернете:

- перенести сюда целиком то, что сейчас рисует `web` в `providers.rs`: включение, прокси, ключ, движок, проверка;
- рядом число слотов поиска, от 1 до 16;
- с карточки провайдеров этот блок убрать.

На карточке провайдера одно поле «Группа»: пустой пункт «без лимита» и имена существующих групп. Нельзя вписать имя, которого нет в списке. Одна группа выбирается у любого числа провайдеров.

Очередь, секция, которая сейчас «Загрузка»:

- подзаголовок «Пулы» и строки только из текущих групп: имя, занятые и свободные слоты, сколько ждёт;
- подзаголовок «Инструменты» и одна строка поиска в интернете в том же виде;
- пять старых видов работ не показывать.

Подсказку `hint_memory`, которая отправляет на страницу «Бюджет», переименовать на «Параметры».

Ключи `en.toml` и `ru.toml` менять парой.

## Проверка

Покрыть тестами:

- провайдер без пула не ждёт, даже если другой пул занят;
- два провайдера в `Single` с лимитом 1: второй ждёт, пока первый не отпустит;
- провайдер в другой группе идёт, пока `Single` занята;
- три ожидающих в одной группе получают слот в порядке прихода, четвёртый новый не вклинивается вперёд;
- удаление группы отпускает ожидающих;
- лимит поиска 1: вторые `web_search` и `web_read` ждут;
- в статусе есть группа с нулём занятых.

Тесты `slots.rs`, `queue.rs`, `budget.rs` и места, где собирается `Budget::default()`, переписать под группы. Не оставлять зелёными старые проверки пяти видов работ.

`cargo test -p mediaa-core -p mediaa-agent`. Тесты пакета `mediaa` не запускать, если меняется только подпись и состав страницы без нового поведения кликов. Сборку `cargo check -p mediaa` сделать.

## Не делать

- Не привязывать `Single` ко всем провайдерам само.
- Не лимитировать провайдера без группы.
- Не оставлять интерактивный обгон.
- Не вводить второй лимит в `pools`.
- Не добавлять лимиты инструментов, кроме поиска и чтения страницы.
- Не писать миграцию старого бюджета.
- Не менять контракт расшифровки и размер кусков звука.
