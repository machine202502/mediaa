# Запуск MediaA вне рабочего дерева

## Цель

`.\scripts\windows\run.ps1` открывает каталоги, а не показывает SQLite код 14.

## Факты

`Catalogs::open` для `Documents\MediaA\.ai\catalogs.db` включает WAL и создаёт
служебный файл рядом с базой. Файл базы целый: схема каталогов 1, очередь версии 2.

Программа, чей exe лежит внутри репозитория, получает отказ в записи и в
`Documents`, и в `%LOCALAPPDATA%`, и во временной папке пользователя. Та же
программа, скопированная наружу, эти пути пишет. Терминал Cursor и отдельный
PowerShell тут ни при чём: оба запускают `target\debug\mediaa.exe`.

## Решение

`run.ps1` делает `cargo build` и запускает копию из
`%LOCALAPPDATA%\mediaa\dev-run\mediaa.exe`.

Уже запущенный процесс из `target` остаётся владельцем single-instance. Его нужно
закрыть до нового запуска, иначе новый процесс только активирует старый.
