# Простые и расширенные настройки

## Цель

По умолчанию показывать только основные настройки. Пользователь может включить
расширенные настройки одной кнопкой/переключателем. Скрытые значения не сбрасываются
и продолжают применяться.

## Модель

- В `Settings` добавляется `advanced_settings: bool`, по умолчанию `false`.
- Вверху страницы настроек — переключатель «Расширенные настройки».
- При выключении скрываются только advanced-строки/секции; значения остаются.
- Если в секции не осталось ни одной простой строки, секция скрывается целиком.
- Переключатель виден всегда.
- Настройка сохраняется между запусками.

## Зафиксированный простой режим

Показывать:

- Внешний вид: тема, язык.
- Запуск: автозапуск, старт в трее.
- Окно: «Закрывать в трей».
- Горячие клавиши и их профили — без изменений, как сейчас, в обоих режимах.
- Захват/Видео (полный экран, окно): источники; формат только MP4/MKV; разрешение
  1080p / 720p / 480p; пресет; включение звука; микрофон; системный звук.
- Захват/Видео (регион): MKV недоступен; остаются WebP/GIF; разрешение
  1080p / 720p / 480p, пресет, аудио/микрофон; quality/fps скрыты.
- Захват/Аудио: только MP3 и WAV, пресет, битрейт, микрофон, системный звук.
- Захват/Скриншот: без изменений, отдельных настроек вывода нет.
- Курсор: настройка скрыта, курсор всегда включён.

Скрывать:

- WebP/GIF как формат видео;
- FPS, качество;
- GIF-цвета, dither, WebP quality;
- no-signal, свёрнутые источники, скрыть в трей, звук в каждом файле;
- tray left click, tray progress, подсветку региона и толщину;
- папки, превью, справку по клавишам;
- Agent не трогаем: у него свои настройки, в этот режим не входит.

Область действия: страница «Настройки» и «Захват → Видео». Конвертация и Agent
остаются как сейчас, без упрощения. Аудио-захват тоже остаётся как сейчас.

## Скрытые значения

Предлагаю при переходе в простой режим **сбрасывать только скрытые advanced-поля**
к простым значениям:

- fps/quality — к выбранному пресету;
- GIF/WebP-настройки — к дефолту;
- no-signal/minimized/hide/every-file — к дефолту;
- если текущий формат видео GIF/WebP — принудительно MP4;
- если текущий формат региона MKV — принудительно WebP;
- курсор — включить.

Если формат недоступен в простом режиме, настройки принудительно выставляются в
простые значения для доступного формата; выбор пользователя не сохраняется.

Видимые значения (разрешение, пресет, аудио, хоткеи) не сбрасываются.

Почему так: иначе в простом режиме остаётся невидимое состояние — пользователь видит
Quality, а внутри стоит кастомный fps/quality, и поведение записи непредсказуемо.
Без миграций и с простым режимом по умолчанию это чище.

Нет.

## Запись и настройки

Настройки записи фиксируются в момент старта: `RecordingRequest` получает копию
`RecordSettings`, `AnimSettings` и аудио-настроек. Дальнейшие изменения `Settings`
не должны влиять на текущую сессию.

Правила:

- во время записи аудио, региона, экрана или окна настройки, влияющие на запись,
  недоступны для изменения;
- переключатель простых/расширенных настроек во время записи также недоступен;
- даже если настройки изменились программно/из другого места, текущая запись
  продолжает использовать снимок, сделанный на старте;
- после остановки новые настройки применяются только к следующей записи;
- переключение advanced → simple во время записи не должно падать, рвать запись
  или менять её формат/разрешение/аудио.

## Тесты

Тесты — обязательная часть задачи, а не отдельный этап после реализации.

- По умолчанию `advanced_settings = false`, простой набор виден, advanced скрыт.
- Включение переключателя показывает все секции/поля.
- Выключение сбрасывает только скрытые advanced-поля и снова их прячет.
- Настройка сохраняется между запусками.
- Текущий GIF/WebP в обычном видео становится MP4.
- Текущий MKV в регионе становится WebP.
- В простом режиме MKV остаётся в полном экране и окне, но отсутствует в регионе.
- Курсор в простом режиме всегда включён.
- UI snapshots: простые настройки, расширенные, русская светлая тема, минимальная
  ширина.
- Проверка, что в простом режиме нет пустых секций и обрезанных заголовков.

### Запись

- Во время записи аудио/региона/экрана/окна настройки записи и переключатель
  simple/advanced disabled; UI snapshot это показывает.
- Старт записи с настройками A; изменить `Settings` на B; завершить; результат
  соответствует A, не B.
- Аудио: старт с MP3/256, переключить на FLAC/128 во время записи; итоговый файл
  остаётся MP3/256.
- Регион: старт с 720p/GIF; переключить на простой (1080/WebP); итоговый файл
  остаётся 720p/GIF.
- Экран/окно: старт с MKV/1080p; переключить в простой (MP4); текущая запись
  остаётся MKV.
- Переключение advanced → simple во время записи: приложение не падает, запись
  останавливается и сохраняется, следующий старт использует простые настройки.
- Попытка изменить настройки через UI во время записи не меняет текущий снимок.
- UI snapshots: Settings в состоянии записи (simple и advanced), запись региона и
  аудио.

## Статус

Реализовано: простой режим по умолчанию, переключатель, скрытие полей и сброс
скрытых значений, принудительные форматы, snapshots простых/расширенных настроек и
тест переключения режима во время записи.
