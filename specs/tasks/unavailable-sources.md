# Запись недоступных источников

## Решение

Настройка профиля:

- поле: `allow_unavailable_sources`;
- UI: «Разрешить запись свёрнутых окон и отключённых мониторов»;
- по умолчанию **выключена**;
- действует на App и Hotkey;
- для Region настройка не показывается и всегда действует запрет: запись региона с недоступным
  монитором отклоняется.

Поведение на старте:

| Ситуация | Настройка выключена | Настройка включена |
|---|---|---|
| Окно свёрнуто | ошибка, вся запись отклоняется | запись с сохранённым размером, fake/чёрный, предупреждение |
| Окно закрыто/исчезло | ошибка | ошибка |
| Окно скрыто, но не свёрнуто | ошибка | ошибка |
| Монитор отключён | ошибка | запись с размером из списка, fake/чёрный, предупреждение |
| Монитор отключён во время записи | fake/чёрный, запись продолжается | fake/чёрный, предупреждение |

Гарантия по умолчанию — **только старт**: если настройка выключена, недоступный источник
не даёт начать запись. Во время уже начатой записи потеря источника не останавливает запись.

## Закрытое окно

Закрытое окно нельзя дождаться. Даже при включённой настройке это ошибка и отказ всей записи.

## Идентичность окна

Хранить в `WindowInfo`:

- `id` (HWND);
- `pid`;
- `app` / класс окна.

Не сравнивать заголовок: он меняется. При старте проверять:

1. HWND существует;
2. PID совпадает;
3. класс/app совпадает;
4. видимость/свёрнутость по настройке.

При несовпадении — ошибка, всю запись отклонить. Заголовок использовать только в сообщении.

## Отложенный источник

Для свёрнутого окна и отключённого монитора нужен `DeferredSource`:

- сразу отдаёт сохранённый размер;
- `available() == false`, пока источник недоступен;
- capture пишет fake/чёрный;
- при восстановлении запускает WGC/захват **в фоне**, не блокируя capture-поток;
- пока первый кадр не готов — fake/чёрный;
- при ошибке захвата повторяет попытку, не завершает запись;
- при смене ID монитора остаётся fake и показывает предупреждение.

Ожидание WGC в `grab()` запрещено: это остановит остальные источники.

## Геометрия

- начальный размер берётся из выбранного `WindowInfo`/`MonitorInfo`;
- размер не меняется в середине записи;
- после разворота кадр вписывается с сохранением пропорций;
- апскейла нет;
- при несовпадении — чёрные поля.

## Уведомления

- старт с недоступным источником при включённой настройке — предупреждение;
- постоянный индикатор «Источник недоступен — заглушка/чёрный экран»;
- восстановление — «Источник восстановлен»;
- смена ID монитора — постоянное предупреждение.

## Тесты

### Настройки и UI

- default `allow_unavailable_sources == false` для всех профилей;
- включение только у выбранного профиля;
- чекбокс отображается, tooltip;
- UI snapshot.

### Preflight, настройка выключена

- свёрнутое окно → ошибка, вся запись отклонена, файлов нет;
- отключённый монитор → ошибка;
- закрытое окно → ошибка;
- один недоступный из нескольких → не стартует ни один источник.

### Preflight, настройка включена

- свёрнутое окно → старт, сохранённый размер, fake/чёрный;
- отключённый монитор → старт, сохранённый размер;
- закрытое окно → всё равно ошибка;
- окно скрыто, но не свёрнуто → ошибка.

### Идентичность

- тот же HWND, другой PID → ошибка;
- тот же HWND, другой класс/app → ошибка;
- изменился только заголовок → запись разрешена.

### Отложенный источник

- старт со свёрнутым окном: размер не 234×38;
- разворот: fake сменяется реальным видео;
- capture-поток не зависает, остальные источники идут;
- окно не развернули: fake до конца;
- fake выключен: чёрный до первого кадра;
- монитор вернулся с тем же ID — видео;
- монитор вернулся с другим ID — fake + предупреждение.

### Многопоточность и длительность

- один источник свёрнут, второй живой: оба выхода равной длительности;
- свёрнутый источник не блокирует старт;
- обрезка выходов не ломает таймлайн.

### Видео-сценарии

Добавить 30-секундные MP4-сценарии:

- старт со свёрнутым окном → разворот на 10-й секунде;
- старт с отключённым монитором → подключение;
- fake on и fake off;
- сравнительные документы для ручной проверки.

## Проверка

Реализовано:

- `RecordSettings::allow_unavailable_sources`, default `false`, для App/Hotkey; Region его
  игнорирует;
- чекбокс и tooltip в записи;
- `WindowState` с `Available/Minimized/Hidden/Missing/Mismatch`;
- проверка PID/app при старте;
- `DeferredSource` с фоновым worker: не блокирует capture-поток;
- deferred-источники для свёрнутого окна и отключённого монитора;
- старт с сохранённым размером;
- предупреждение `source_allowed`;
- ошибка `target_unavailable`;
- атомарный отказ media-сессии при ошибке начального источника;
- тесты: настройки, UI snapshot, классификация целей, deferred worker, отказ всей записи, 30-секундный MP4-сценарий отложенного окна.
