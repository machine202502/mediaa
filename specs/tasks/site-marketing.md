# Маркетинговый сайт MediaA на GitHub Pages

## Цель

Создать статический промо-сайт приложения MediaA, который деплоится штатным способом GitHub
(GitHub Actions → Pages). Сайт презентует бесплатное приложение маркетинговым языком, визуально
нестандартный: WebGL-шейдеры, CSS-3D, заметные анимации и реальные скриншоты UI.

## Контекст

- Приложение: MediaA — кросс-платформенный захват экрана на Rust (один исполняемый файл,
  FFmpeg статически внутри).
- Позиционирование на сайте: поддержан только Windows (кросс-платформенность не выносится в
  маркетинг, пока не отлажена).
- Смысл приложения и фокус сайта: скриншоты области/окна/экрана с аннотациями, запись
  экрана/области/окон (MP4/MKV, GIF/WebP), запись аудио (микрофон/системный звук) и
  конвертация форматов. Библиотека — служебное хранилище результатов и в маркетинговую
  подачу не выносится.
- Репозиторий: https://github.com/machine202502/mediaa. Проектный Pages-сайт публикуется по
  базовому пути `/mediaa/`.
- Готовые скриншоты UI лежат в `crates/app/tests/snapshots/*.png` (результаты UI-регрессии).
- Приложение бесплатное, open-source (MIT; бинарники под GPL из-за libx264). Released-версий
  пока нет, поэтому кнопка загрузки ведёт на репозиторий GitHub.

## Ограничения

- Сайт статический, без сборщика и внешних runtime-зависимостей (CDN не обязательна), чтобы
  Pages-деплой был самодостаточным.
- Не менять Rust-код, тесты и их snapshot-файлы.
- Коммит и push — только после явного разрешения пользователя (правила Git в `rules.md`).

## Решение

- `site/index.html`, `site/assets/css/style.css`, `site/assets/js/main.js` — самодостаточный
  лендинг на чистом HTML/CSS/JS. Содержание — только захват, запись и конвертация. Два языка
  (EN/RU) с переключателем и автоопределением по `navigator.language`; тексты хранятся в
  словаре внутри `main.js` и подставляются через `data-i18n` / `data-i18n-alt` /
  `data-i18n-content`.
- WebGL-фон (domain-warped fbm, сине-голубая aurora-палитра без привязки к курсору), CSS-3D
  фигуры в hero, scroll-reveal, счётчики, 3D-tilt карточек. Эффект «свечения за мышкой» и
  parallax чипов убраны.
- Скриншоты копируются из snapshot-каталога в `site/assets/img/`.
- Favicon и логотип — реальная иконка приложения: PNG сгенерирован тем же алгоритмом, что
  `crates/app/src/icon.rs` (`icon.png` 256px, `icon-512.png` 512px).
- Палитра и кнопки переведены в цвета иконки/интерфейса приложения: синий `#2563EB`, голубой
  `#22D3EE`; кнопки — со скруглением. По мере прокрутки палитра лишь слегка подкрашивается в
  фиолетовый (сдвиг ограничен 30%, внизу преобладает синий; JS интерполирует CSS-переменные и
  WebGL-uniform), буквы в `Convert.`/`Конвертируй.` и в финальном `Free.`/`Бесплатно.`
  покачиваются с задержкой по буквам.
- Галочки в списках нарисованы CSS-границами (2px, поворот 45°) внутри круга, а не текстовым
  символом `✓` — ровное выравнивание.
- На рамках изображений в pillar- и bento-карточках — световой блик через masked
  `backdrop-filter` (`brightness/saturate/contrast`), а не белый градиент поверх картинки.
  Маска — мягкая диагональная полоса; её угол (`--tilt-angle`) и сдвиг (`--mask-shift`)
  вычисляются из наклона карточки, без слежения за курсором. Добавлена лёгкая soft-light
  подсветка углов. Наклон карточки ±1.2°, зум изображения убран.
- Скриншот записи выводится через отдельный WebGL-шейдер CRT: barrel-искривление, скан-линии,
  RGB-маска, хроматическая аберрация по краям, виньетка, бегущая полоса обновления, мерцание,
  периодический шум и редкие горизонтальные разрывы. Картинка приближена (zoom 0.94), чтобы
  искривлённый экран заполнял кадр без чёрной рамки. Если WebGL/текстура недоступны, остаётся
  обычный `<img>`-fallback.
- Первые 0.5 с CRT показывает только контрастный анимированный шум (~18 fps, редкие белые
  строки), затем картинка «ловит сигнал» и проявляется.
- Периодически (два независимых расписания ~7.3 с и ~11.1 с) на 70–300 мс включается такой же
  анимированный шум, поэтому срывы сигнала идут с разными промежутками.
- Плавающие чипы упрощены (по просьбе пользователя): без орбит, колец, шлейфов и сквозных
  переходов. Они на переднем плане в фиксированных позициях по краям окна и мягко дрейфуют
  (`translate`/`rotate` на несколько px) с разными периодами. Оформление — иконка в бейдже,
  двухстрочный текст, акцентная рамка и периодический блик. REC-таймер не перекрывают; на
  ширине ≤1120px скрываются.
- Номера карточек `01/02/03` перенесены с плавающих бейджей поверх скриншотов в заголовок
  карточки: крупный градиентный индекс с тонкой линией-разделителем перед названием.
- Прогресс-бар конвертации при попадании карточки в viewport заполняется 0→85% за 5.2 с с
  cubic ease-out (плавное замедление и остановка). Осталась только двойная пульсация яркости
  заливки (heartbeat); glow оболочки и glint убраны. Процент в подписи синхронизирован.
- Текст `MP4 → GIF ·` плавает по буквам очень слабо (амплитуда ±0.6px), цвет остался прежним
  `var(--muted)`; процент вынесен в отдельный живой счётчик.
- В финальной CTA-карточке вращающийся conic-свет удалён: вместо него два локальных туманных
  пятна (`radial-gradient` + `blur` + `screen`), которые медленно дрейфуют и «дышат» с разными
  периодами, плавно растворяясь по краям; текст остаётся выше тумана.
- В hero — low-poly 3D-камера из CSS-граней (старая модель, выбранная пользователем; не
  заменять на камкодер), собранная через `preserve-3d` и вращающаяся по X/Y как куб.
- Камера подсвечена: мягкий bloom-ореол (`cam-bloom`), блик объектива (`lens-glint`), rim-
  подсветка граней; красный REC-индикатор делает плавный импульс с яркой вспышкой и
  затухающим свечением (1.8s ease-in-out).
- 4D-тессеракт и кольцо удалены по просьбе пользователя; в hero остаются камера и верхняя сфера.
- Entrance-анимация остаётся у камеры: прилетает из глубины (`scale .02 → 1`), финальный
  подход плавный, без overshoot; `perspective` на 3D-сцене, при `prefers-reduced-motion`
  сразу в конечном состоянии.
- `.github/workflows/pages.yml` — официальный Pages-деплой: `configure-pages`,
  `upload-pages-artifact` (path: `site`), `deploy-pages`.

## Проверка

- `node --check site/assets/js/main.js` — синтаксис JS.
- Проверить, что все локальные ссылки на CSS/JS/картинки существуют.
- Локально открыть `index.html` и прогнать smoke-проверку разметки (без визуальной регрессии).

Фактически выполнено: JS прошёл `node --check`; все локальные ссылки на ассеты существуют;
headless-прогон через Playwright + Edge на 1440px и 390px — ноль console/page errors, ноль
404, изображения и WebGL-канвас создаются, горизонтального переполнения нет. Переключатель
EN/RU проверен в обе стороны (title, заголовок, статистика и `html lang` меняются, выбор
сохраняется в `localStorage`). Карточка «Говорит по-русски» удалена. Копирайт не содержит
Linux/macOS/кросс-платформенности; в hero и футере указан только Windows.
Проверено: после анимации заголовок состоит из посимвольных `.wobble-letter`, радиус кнопки
18px, наверху страницы `--g1` = `#1d4ed8`, внизу остаётся преимущественно синим (сдвиг
ограничен).

## Материальные риски

- Без push и включения Pages в настройках репозитория деплой не запустится — это требует
  действий пользователя.
- Проектный Pages-сайт живёт под `/mediaa/`; используются относительные пути, чтобы не зависеть
  от базового пути.
