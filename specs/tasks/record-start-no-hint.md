# Без подписи под кнопкой записи

## Решение

Под кнопкой «Начать запись» больше нет текста «Сначала выберите область» и любых других
пояснений. Причина недоступности кнопки показывается только в tooltip.

## Изменения

- `crates/app/src/pages/record.rs` — убран `theme::hint` под кнопкой;
- причина недоступности осталась в `on_disabled_hover_text`.

## Проверка

- UI-снапшоты записи;
- `cargo test -p mediaa --lib`;
- `clippy`.
