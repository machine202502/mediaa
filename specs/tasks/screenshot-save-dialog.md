# Сохранение скриншота области через системный диалог

## Цель

Кнопка сохранения в оверлее области открывает системный диалог: пользователь выбирает папку,
имя и формат (PNG/WebP). Оверлей не закрывается, пока файл не записан; «Отмена» в диалоге
возвращает к выбору области.

## Решение

- Одна кнопка «Сохранить…» вместо «Сохранить PNG/WebP». Формат берётся из расширения итогового
  пути, а не из фильтра: `resolve_save_path` принимает только `png`/`webp`, без расширения
  подставляет формат из настроек (`screenshot.format`).
- Имя по умолчанию — `Screenshot_<дата>` без расширения, чтобы фильтр диалога подставил
  выбранный формат; каталог — `media_dir`.
- Запись выполняется в оверлее синхронно (`mediaa_storage::screenshot::save`), после успеха
  выставляется `Outcome::Saved { path, size }`, и только тогда оверлей закрывается. При ошибке
  текст остаётся в панели действий.
- Перед диалогом окно оверлея на один кадр переводится в `WindowLevel::Normal`, после диалога —
  обратно в `AlwaysOnTop`: иначе системный диалог может оказаться под полноэкранным оверлеем.
- Автосохранение (хоткей, трей, Enter по умолчанию) не меняется и по-прежнему пишет в библиотеку
  без диалога.

## Файлы

- `crates/app/src/overlay.rs` — `Outcome::Saved`, `SaveDefaults`, диалог, запись, уровень окна.
- `crates/app/src/overlay/editor.rs` — одна кнопка сохранения, Ctrl+S, показ ошибки.
- `crates/app/src/app/actions.rs` — уведомление и обновление библиотеки для готового файла.
- `crates/app/locales/{ru,en}.toml` — «Сохранить…», подсказка и ошибка формата.
- `crates/app/src/app/capture.rs` — передача каталога и формата по умолчанию.
- Снапшоты `region-editor-*` обновлены после просмотра diff (панель действий стала уже).

## Проверка

- `cargo test -p mediaa --lib`: 250 тестов.
- Тест `region_editor_selects_annotates_and_saves` пишет настоящий PNG и проверяет
  `Outcome::Saved`; `the_extension_of_the_save_path_decides_the_format` проверяет PNG/WebP,
  регистр, отсутствие расширения и отказ для `.jpg`.
- `cargo clippy --workspace --all-targets`, `cargo fmt --all`.

## Риск

Поведение системного диалога поверх полноэкранного always-on-top оверлея проверено только
логикой смены уровня окна; живой прогон с реальным выбором области не выполнялся.
