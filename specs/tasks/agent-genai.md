## Сквозные правила поведения

Спикеры уходят в запрос только если включены обе галочки: на модели речи и в анализе этого
ролика. Галочка модели выключена — галочка ролика ничего не запрашивает. В интерфейсе анализа
её тогда показывают выключенной и неактивной. По умолчанию у ролика диаризация выключена.

Время слов — отдельная галочка модели речи, по умолчанию выключена. Выключена: в расшифровке
текст есть, время стоит на весь кусок, повторы на стыке не вычитаются. Включена: просим время
каждого слова и на стыке оставляем слово один раз.

Окно одно на слова и спикеров. Диаризация ролика включена и модель её разрешает: 480 с,
перекрытие 15 с. Иначе: 600 с, перекрытие 2 с.

Склейка текста есть всегда. Спикеры добавляются только в первом режиме. Перекрытие связывает
того, кто говорит через границу. Отпечаток добавляется только у провайдера расшифровки, только
при его галочке и только вместе со спикерами. Метки спикеров вроде `"A"` живут внутри одного
ответа. Между кусками их сводит наша склейка.

OpenAI-совместимый ответ не содержит и время слов, и спикеров сразу. Обе галочки включены —
два запроса на кусок: `verbose_json` и `diarized_json`. Оба должны удаться, иначе кусок не
считается готовым. Наш сервер расшифровки может вернуть текст, слова, сегменты и
`speakers[].embedding` одним телом.

Контекст, включение размышлений и глубина стоят на модели агента и на модели заголовков, не на
подключении. Глубина: `low`, `medium`, `high`, `xhigh`, по умолчанию `medium`. Размышления
выключены — поле глубины не отправляем. Включены — отправляем выбранное слово. Диапазон
2048–262144 больше не зажимаем. Проверка по подстрокам `qwen3`, `deepseek`, `reason` удаляется.

Кнопка «Проверить модели» остаётся: список имён с сервера, выбранное имя должно в нём быть.

Реранк, скачивание Ollama и отмена остаются нашими. `genai` их не делает.

## AGENT-GEN-2. Чат и эмбеддинги через genai

Цель: чат и эмбеддинги ходят через `genai`. Реранк, список моделей, проверка имени, pull Ollama
и расшифровка остаются текущим HTTP.

Файлы: `Cargo.toml`, `Cargo.lock`, `crates/engine/src/openai.rs`, `crates/engine/src/ollama.rs`,
`crates/engine/src/engine/mod.rs`, `crates/engine/src/presets.rs`, `crates/agent/src/assistant/brain.rs`.

Сделать:

- Зависимость `genai`. Tokio снова допустим.
- На каждое подключение свой клиент. Прокси берётся из подключения.
- Эмбеддинги Ollama идут нативным путём `genai`, не через OpenAI `/embeddings`.
- Префиксы запросов для эмбеддингов, которые код добавляет до HTTP, сохранить до вызова.
- Включённые размышления отправляют выбранное слово: OpenAI `reasoning_effort`, OpenRouter
  `reasoning.effort`, Ollama `think`. Выключены — эти поля не отправлять.
- Контекст модели передавать в запрос как есть.
- `models()` и `check()` не переводить на `genai`: список имён и сверка выбранного имени

Риск: `genai` не гарантирует эмбеддинги на произвольном base URL. Для Ollama использовать его
адаптер. Для Custom OpenAI оставить текущий HTTP эмбеддингов, если адаптер `genai` этот URL не
принимает. Это записать в итоге задачи, не подменять молча.
