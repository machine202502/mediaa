# Массовые операции в библиотеке

## Цель

Выделять несколько карточек и выполнять над ними общие операции. Выделение
произвольное; отдельного «выбрать все» нет. Дни выбираются по заголовку подраздела
«Сегодня / Вчера / Позавчера / дата».

## Выделение

- Обычный клик по карточке — выбрать только её.
- Клик по превью тоже выбирает карточку, кроме клика по таймлайну: там
  срабатывает перемотка.
- Свободные места карточки, название и полоса под превью выбирают карточку.
- Клик по активным кнопкам карточки не меняет выделение.
- `Ctrl+клик` — добавить/убрать.
- `Shift+клик` — диапазон от последней выбранной.
- `Esc` — снять всё.
- Двойной клик — открыть просмотр.
- Клик по заголовку дня — выбрать все видимые карточки этого дня; повторный клик
  снимает выделение со всего дня.
- Смена фильтра, поиска или сортировки сбрасывает выделение.
- «Выбрать все» и `Ctrl+A` не делаем.
- У выбранной карточки меняется цвет всей карточки и появляется акцентная рамка
  вокруг всей карточки, а не только превью.
- При непустом выделении по центру заголовка появляется навесная кнопка
  «Выбрано N» со списком массовых операций. Она не двигает layout и остаётся на
  месте при прокрутке. Рядом с ней — крестик, который снимает всё выделение.
- В меню трёх точек карточки есть отдельный пункт «Выделить».
- Тот же список — в контекстном меню выбранной карточки.

## Операции

Выпадающий список строится из расширяемого списка `BulkAction`, чтобы потом
добавлять пункты без переделки UI.

- **Переименовать** — для одной карточки текущий диалог; для нескольких — базовое
  имя и автоматическая нумерация в порядке отображения:
  `Имя 1.ext`, `Имя 2.ext`, ... (пробел перед номером); расширение сохраняется.
- **Удалить** — всегда в корзину, и одиночное, и массовое, и cleanup. Если корзина
  недоступна — ошибка, без fallback на безвозвратное удаление.
- **Копировать файлы** — список файлов в буфер, чтобы вставить в Explorer.
- **Копировать пути** — абсолютные пути, по одному на строку, без кавычек.
- **Отправить в конвертацию** — перейти в Convert с выбранными файлами.
- **Снять выделение**.

## Конвертация

- Если конвертация уже идёт — отправка блокируется.
- По умолчанию выбранные файлы **добавляются** к текущему списку Convert.
- В настройках появляется опция поведения: добавлять (по умолчанию) или заменять.
- Дубликаты схлопываются, порядок — порядок отображения.
- Дальше действует матрица совместимости из `multi-file-conversion.md`.

### Граница с Convert

Библиотека только передаёт пути. Она не следит за конвертацией:

- не хранит статусы, прогресс и ошибки конвертации;
- не показывает бейджи/индикаторы на карточках;
- не знает, что происходит с файлами после отправки;
- не имеет retry для конвертации.

Всем этим владеет только Convert. Библиотека не следила за конвертацией раньше и
не должна никогда.

## Ошибки

- Ошибка одного элемента не останавливает остальные.
- Успешные элементы убираются из выделения; неудачные остаются выделенными и
  помечаются ошибкой.
- В библиотеке нет retry и кнопок повтора: ни в меню, ни на карточках.
- После операции показывается итог: сколько выполнено, сколько ошибок и какие файлы
  не удалось обработать.

## Удаление

- Одиночное, массовое и cleanup используют один путь «в корзину».
- Подтверждение: «Удалить N файлов в корзину?».
- Если корзина недоступна, файлы не удаляются; показывается ошибка с retry.
- Кэши/preview чистятся отдельно, как и сейчас.

## UI

- Тулбар: счётчик выбранных и dropdown.
- В списке: выбранные, упавшие (красные) и обычные карточки.
- После массовой операции — итог: сколько выполнено, сколько ошибок.
- Никаких retry-кнопок в библиотеке.
- UI snapshot: выделение, dropdown, красная упавшая карточка.

## Тесты

Тесты — обязательная часть задачи. UI-снимки и интерактивные тесты пишутся вместе с
реализацией, а не после.

- Выделение: клик, Ctrl, Shift, Esc, день, сброс при смене фильтра.
- Dropdown: состав и доступность действий.
- Rename: нумерация, расширение, коллизии, частичная ошибка и отчёт.
- Delete: всегда корзина; ошибка корзины не удаляет файл; отчёт.
- Copy files/paths: содержимое буфера, абсолютные пути; ошибка не останавливает
  остальные.
- Send to conversion: блок при активной конвертации, add/replace, дедупликация.

## UI-тесты и snapshots

Всё проверяется через `egui_kittest` + PNG-snapshots, как остальные страницы.

Обязательные снимки:

- `library-bulk-selected` — несколько выбранных карточек с рамкой/галочкой и
  тулбаром «Выбрано N ▾»;
- `library-bulk-day` — выбран весь день, заголовок дня в состоянии выбора;
- `library-bulk-menu` — открытый dropdown со всеми операциями;
- `library-bulk-rename` — диалог переименования с превью `Имя 1.ext`,
  `Имя 2.ext`;
- `library-bulk-delete` — подтверждение удаления N файлов в корзину;
- `library-bulk-error` — упавшая карточка красная, без retry-кнопки, плюс итог
  операции;
- `library-bulk-narrow` — тулбар и dropdown на минимальной ширине;
- `library-bulk-russian-light` — русская светлая тема.

Интерактивные тесты:

- клик, Ctrl+клик и Shift+клик меняют выделение;
- повторный клик по дню снимает весь день;
- Esc и смена фильтра очищают выделение;
- dropdown вызывает нужное действие;
- rename реально переименовывает файлы и не ломает расширение;
- delete вызывает корзину, а не `remove_file`;
- copy paths кладёт абсолютные пути;
- send to conversion добавляет/заменяет и блокируется при активной конвертации.

## Как это выглядит

```text
Library
[Все] [Видео] [Аудио]                 [Выбрано 3 ▾]
────────────────────────────────────────────────────
Сегодня                         [Выбрать день]
[✓ card 1] [✓ card 2] [ card 3]
[ card 4] [✓ card 5]

Выбрано 3 ▾
  Переименовать
  Удалить в корзину
  Копировать файлы
  Копировать пути
  Отправить в конвертацию
  Снять выделение
```

## Статус

Реализованы выделение, выбор дня, меню, copy/convert/delete/rename; библиотека не следит за конвертацией. Есть unit-тесты и snapshot выделения.
