### 2026-10-21 — Конвейер анализа, вся работа в очереди, разбор тем, чат как в агентных системах (бывшие 11.1, 11.2, 6.3, 7.4, 7.5, 3.9, 1.2)

* Проект — [pipeline.md](pipeline.md). Очередь — граф задач: составные задачи с подзадачами,
  зависимости, задачи, которые ведёт сам вызывающий (ответ чата), статистика (вызовы модели,
  токены, время, модель), оценка остатка по скорости и по истории, история 30 дней.
* Анализ записи — составная «Анализ» из отдельных задач: распознавание → диаризация → индекс →
  темы (план → сводка каждой темы → склейка) → разбор каждой темы. Перед запуском — окно выбора
  стадий; меню «⋯» вместо «Расшифровать заново»: заново/добавить любую стадию с подтверждением
  того, что пересоберётся, «Остановить». Записью можно пользоваться, как только есть реплики;
  остальное появляется по готовности данных. Ход анализа со временем и «≈ осталось» в студии.
* Вся работа моделей идёт через задачи очереди (`Scope`): фоновые стадии, ответ в чате — задача
  с шагами модели и инструментами. Страница «Очередь» — дерево с прогрессом, временем, оценкой,
  токенами, моделью, фильтрами; подписи задач из локалей.
* Разбор темы: модель сама выбирает 2–6 разделов под тему, пункты с проверенным временем (строки
  по предложениям); режим чтения — блок тем на всю высоту «Диалога», время пункта переводит плеер.
* Чат: лента шагов вниз, размышления живьём (переключатель «Размышления» у модели, по умолчанию
