## Сделано

### 2026-10-15 — Агент: фазы P0–P5

Подробности по фазам — в [agent.md](agent.md), раздел «Phases».

* **P0–P1. Основа работы с моделями:**
  * бюджет и планировщик моделей (слоты, аренда памяти, round robin);
  * llama.cpp с Vulkan;
  * загрузка моделей с Hugging Face;
  * ключи API в системном хранилище паролей;
  * проверка моделей.
* **P2. Распознавание речи:**
  * sherpa-onnx: Silero VAD, GigaAM v3 CTC с пунктуацией, диаризация pyannote + WeSpeaker;
  * возобновляемая задача `transcribe`;
  * панель «Диалог».
* **P3. Поиск и главы:**
  * чанки по репликам, FTS5 со стеммингом, эмбеддинги EmbeddingGemma;
  * гибридный поиск RRF + реранкер BGE v2 M3;
  * главы и сводки (задача `outline`);
  * поиск по папке.
* **P4. Агент:**
  * цикл агента (JSON-шаги по грамматике, защита от повторов, проверка цитат);
  * стриминг ответа;
  * скан всей записи;
  * память чата и свёртка истории;
  * инструменты `plan`, `say`, `rename_speakers`, `delegate`;
  * чат по папке.
* **P5. Веб и бюджет:**
  * инструменты `web_search` и `web_read` (DuckDuckGo, SearXNG, Brave, Tavily, прокси);
  * фильтр ссылок на страницы, которые агенту не показывали;
  * карточка «Загрузка» в очереди (память GPU/RAM, слоты);
  * системный шрифт символов как запасной.
* Первый коммит `83cc59e` (ветка `main`).

### 2026-10-15 — Проверка моделей: папка без GGUF — ошибка

* Для ролей llama.cpp (агент, заголовки, эмбеддинги, реранкер) папка без `.gguf` теперь даёт
  ошибку проверки «no GGUF model inside … choose a repository with GGUF files», а не
  «готово: N файлов».
* «Файлы на месте» осталось только для роли синтеза речи.
* Код — `crates/agent/src/check.rs`.

## Отклонено

* **Переход на llama.cpp «для универсальности форматов» (20).** Снято пользователем. Мысль
  покрывается задачей «движок инференса отдельно от приложения» (todos.md, 4.3).
* **Очереди и задачи на Temporal (19).** Отклонено: нужен отдельный сервер, а приложение должно
  быть одним exe и работать офлайн. Взамен — устойчивая сессия агента на SQLite
  (todos.md, 3.4).
* **Встроенный (вшитый в приложение) движок как отдельный режим.** Пользователь не хочет:
  движок ставит пользователь (todos.md, 4.3).
* **Модели распознавания в форматах onnx-asr, faster-whisper (CTranslate2) и whisper.cpp
  (GGML).**
  * У onnx-asr другой препроцессинг и нет метаданных sherpa-onnx.
  * whisper.cpp конфликтует по символам ggml с llama.cpp в одной сборке.
  * Поддерживаются семейства sherpa-onnx (todos.md, 1.1).
* **Безголовый браузер для веб-поиска.** Тяжело и ломает «один exe» (todos.md, 5.1).

### 2026-10-20 — Подагенты на DeepSeek через OpenRouter (бывшая задача 11.1)

* Скрипт [../scripts/subagent.sh](../scripts/subagent.sh) запускает безголовый Claude Code
  на модели `deepseek/deepseek-v4.1-flash-1017` через OpenRouter (`--provider openrouter`,

  окружения, не в репозитории.
* Разрешение на запуск скрипта — `.claude/settings.local.json` (в `.gitignore`).
* Проверено: DeepSeek работает с файлами, браузером VS Code и отладчиком. Как пользоваться —
  [dev-context.md](dev-context.md), «Как работаем».
