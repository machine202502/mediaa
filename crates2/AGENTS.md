# MediaA 2: правила

Это отдельный workspace. Старые `specs/architecture.md`, `specs/rules.md` и раскладка
`crates/` описывают предыдущее приложение; для кода под `crates2/` действуют правила ниже.
Дизайн и этапы: [rewrite-crates2.md](../specs/tasks/rewrite-crates2.md).

## Границы

1. Девять крейтов: `core`, `i18n`, `protocol`, `storage`, `platform`, `media`, `backend`,
   `frontend`, `app`. Новый крейт — только с удалением другого или явным решением.
2. Зависимости: `core` — фундамент; `protocol` — только `core` + serde; `storage` — только
   `core` + SQLite; `platform` — `core`; `media` — `core`, `platform`; `backend` — всё, кроме
   `frontend`; `frontend` — `core`, `i18n`, `protocol`, `platform`, `media` только для чтения;
   `app` — `backend` и `frontend`.
3. `frontend` не импортирует `storage`, `backend`, не открывает SQLite, не пишет медиа и не
   запускает запись/конвертацию.

## Состояние

4. Backend — единственный владелец доменного состояния и эффектов. UI — проекция.
5. Один домен — один `apply(state, event, now) -> (state, Vec<Effect>)`. Без I/O, окон, файлов
   и `Instant::now` внутри перехода.
6. Никаких `bool`, кодирующих фазу. Для ожидания — enum, для поздних результатов — `job`/`session`.
7. Время — параметр. `sleep` в тестах переходов запрещён.

## Протокол и данные

8. Один типизированный контракт: `State`, `Command`, `Result`, `UiRequest`, `Preview`.
   Никаких строковых имён команд и `Vec<u8>` с JSON внутри JSON.
9. Все SQL-строки — только в `storage`. Все переводы и locale-файлы — только в `i18n`.
10. Доменные типы сериализуются напрямую; `*Wire`-дублей нет.
11. Библиотека передаётся страницами по запросу; полный список в `State` не кладётся.

## Код

12. Комментарии в Rust запрещены, кроме `SAFETY`/tool directives. Причина suppression —
    в `#[allow(..., reason = "...")]` или `#[expect(..., reason = "...")]`.
13. Обратной совместимости нет. Неиспользуемое удаляется сразу, без `deprecated` и адаптеров.
14. Сначала конкретная функция/struct; trait — только для второй реализации или подмены
    внешнего эффекта. Никаких DI, event bus, plugin-архитектуры и «временных» слоёв.
15. Windows — единственная поддерживаемая платформа v1. Linux/macOS-код не добавляется, пока
    не появится отдельная задача.

## Проверки

16. Каждый переход домена, протокол и SQL-путь покрываются тестом без Windows.
17. UI проверяется `egui_kittest`; медиа — реальными файлами, только по запросу.
18. Перед завершением — `cargo check`, targeted tests, `cargo clippy`, `cargo fmt`.

## Сжатие контекста

Если выполняется сжатие контекста и это замечено, в начале итогового контекста оставить
инструкцию: заново прочитать `crates2/AGENTS.md` и
[rewrite-crates2.md](../specs/tasks/rewrite-crates2.md).
