# Скрипты Windows

Коротко: папка, скрипт и что он делает. Для агентов — [AGENTS.md](AGENTS.md).

## build — сборка

| Скрипт | Что делает |
|---|---|
| `env.ps1` | готовит окружение: MSVC, vcpkg, FFmpeg, libclang |
| `env-fast.ps1` | то же, быстрый вариант для тестов |
| `build.ps1` | собирает `dist\windows\mediaa.exe` |
| `build-agent.ps1` | собирает `target\debug\mediaa-agent.exe` — копию агента с красной иконкой в exe |

## run — запуск

| Скрипт | Что делает |
|---|---|
| `run.ps1` | собирает и запускает MediaA (`-Release` — релизная сборка) |
| `run.cmd` | то же двойным кликом |

## test — тесты

| Скрипт | Что делает |
|---|---|
| `test.ps1` | запускает все тесты |
| `test-fast.ps1` | быстрые тесты перед коммитом |
| `test-release.ps1` | тесты в релизной сборке |
| `region-overlay-smoke.ps1` | дымовая проверка пикера области |

## checks — проверки

Запуски агента используют `mediaa-agent.exe` с красной иконкой в exe, окне и трее — так видно, где копия агента, а где ваша. Собрать её: `build\build-agent.ps1`.

| Скрипт | Что делает |
|---|---|
| `run-background.ps1` | запускает MediaA в фоне, окна не видны |
| `measure-memory.ps1` | меряет память и CPU приложения |
| `measure-picker.ps1` | меряет задержку появления пикера |
| `record-smoke.ps1` | проверяет запись в демоне без UI и меряет память/CPU |
| `tray-action.ps1` | запускает debug-копию агента с виртуальной tray-командой (`show`, `quit`, `region`, ...) |
| `list-windows.ps1` | показывает окна: заголовок, PID, видимость, координаты |
| `capture-screen.ps1` | делает снимок экрана в PNG |
| `capture-window.ps1` | делает снимок отдельного окна по заголовку или хэндлу |
| `send-input.ps1` | подаёт тестовые клавиши и мышь в приложение, без реальной клавиатуры |
