# Скрипты Linux

Коротко: скрипт и что он делает. Для агентов — [AGENTS.md](AGENTS.md).

| Скрипт | Что делает |
|---|---|
| `build.sh` | собирает `dist/linux/mediaa` |
| `build-docker.sh` | сборка в контейнере Ubuntu 24.04 |
| `build-docker.ps1` | то же из Windows |
| `Dockerfile` | образ для сборки в Docker |
| `install-runtime-deps.sh` | ставит системные зависимости |
| `smoke-test.sh` | дымовой тест в контейнере |
| `smoke-test-docker.ps1` | дымовой тест из Windows |
| `../wsl/run-linux.ps1` | запуск Linux-сборки из Windows через WSL |
